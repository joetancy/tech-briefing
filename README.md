# Tech Briefing

Daily engineering and AI briefings, published as Markdown and rendered with GitHub Pages.

## Structure

- `_posts/` — one dated briefing per day
- `index.md` — GitHub Pages home page
- `archive.md` — archive of all briefings
- `_config.yml` — Jekyll configuration

## Publishing

Briefings use the file name format:

```
_posts/YYYY-MM-DD-daily-tech-briefing.md
```

GitHub Pages can publish this repository from the `main` branch and repository root.
